# Decisions (ADRs)

One short, dated markdown file per significant choice. Capture *why* — the thing git can't tell you
(why we picked a host/library, why we rejected an alternative, why a shortcut was acceptable, why we delayed something).

Naming: `NNNN-short-title.md` (e.g. `0001-gemini-live-direct-websocket.md`).

Template:

```markdown
# NNNN — Title

_Date: YYYY-MM-DD_

## Context
What forced a decision.

## Decision
What we chose.

## Why / alternatives rejected
Why this over the others.

## Consequences
Trade-offs, follow-ups, what to revisit.
```
